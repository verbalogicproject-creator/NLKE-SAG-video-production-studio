# NLKE-SAG Video Advanced Production — Knowledge Base

This is a RAG-ready knowledge base of TypeScript/JavaScript video editing libraries, AI video generation tooling, and social-media publishing infrastructure researched for the `NLKE-SAG-video-production-studio` pipeline (Veo + Omni model orchestration, TypeScript app, offline-capable editing pipeline).

## Documents
1. `01-programmatic-video-frameworks.md` — Remotion, Etro, react-video-editor stacks (React/TS video-as-code)
2. `02-ffmpeg-wasm-browser-editing.md` — Client-side/offline WASM video processing
3. `03-nodejs-cli-video-libs.md` — Editly, FFCreator, LosslessCut, node-side declarative editing
4. `04-ai-video-generation-apis.md` — Veo (Vertex AI), video render-as-a-service (Creatomate, Shotstack)
5. `05-speech-captions-auto-editing.md` — Whisper bindings, auto-editor, silence/jump-cut automation
6. `06-social-publishing-apis.md` — Ayrshare, upload-post, multi-platform distribution SDKs
7. `07-architecture-recommendations.md` — How to compose these into an offline-capable, AI-integrated pipeline for NLKE-SAG
