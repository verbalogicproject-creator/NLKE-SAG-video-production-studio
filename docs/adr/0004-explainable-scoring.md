# ADR 0004: Use explainable Clip Quality Score

Status: accepted, 2026-07-27.

SAG reports Hook 30%, Flow 25%, Value 20%, Delivery 10%, Visual Evidence 10%, and Boundary Quality 5%, with evidence, confidence, warnings, content profile, provider identity, and policy version. It does not report an uncalibrated virality prediction. Calibration creates a new revision and does not rewrite historical scores.
