# Routing policy

Route architectural ambiguity, security boundaries, data migrations, and final arbitration to Sol. Route ordinary implementation, integration, debugging, and tests to Terra. Route high-volume read-only discovery, extraction, classification, and log summarization to Luna.

Use Sol for planning and evidence review, not mechanical scans. Luna never edits. Terra gets at most two bounded attempts before escalation. Reuse a result only when its instruction hash, input hash, and repository revision all match.

Every worker returns status, summary, changed files, evidence, assumptions, risks, confidence, and any escalation reason. Evidence means an executed command result or a precise source reference.
